通用專案規則
4

設定 100 年有效期的安全性規則 (通用工具)

這是給 剛好學、剛好白板、剛好簡報 專用的規則，可讓資料在 2125 年前都能讀寫，無需每年更改。 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // 匹配資料庫中的任何文件路徑
    match /{document=**} {
      // 允許讀取和寫入，條件是：當前時間小於 2125 年 1 月 1 日
      allow read, write: if request.time < timestamp.date(2125, 1, 1);
    }
  }
}

GAS 後端部署指南與 Code.gs

請將後端程式碼貼入 Google 試算表綁定的 Apps Script 中

部署步驟說明：

  1. 新增一份 Google 試算表（例如「剛好整合所_資料庫」）。
  2. 點擊上方選單「擴充功能」→「Apps Script」。
  3. 清除原有內容，複製下方 Code.gs 程式碼並貼上存檔。
  4. 點擊右上角「部署」→「新增部署作業」。
  5. 類型選擇「網頁應用程式 (Web App)」，設定如下：
    • 執行身分：我本人
    • 誰可以存取：任何人 (Anyone)
  6. 複製部署後的 Web App URL，回到本網頁點擊右上角 ⚙️ 連接設定 貼上即可！
